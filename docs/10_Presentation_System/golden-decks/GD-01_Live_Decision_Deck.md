# GD-01 — Live Decision Deck

> Status: Planned  
> System Version: 0.9.0

## Brief

Create a concise executive decision deck that enables one explicit decision in a live meeting.

## Required Structure

1. Decision required
2. Context and urgency
3. Governing Message
4. Options
5. Evaluation criteria
6. Trade-offs
7. Recommendation
8. Decision and next actions

## Validation Focus

- Live readability
- One message per slide
- Decision clarity
- Options and trade-offs
- Presenter pacing
- Projection conditions

## Required Review

- Release Gates
- Risk-based Audit when the decision is executive-critical
